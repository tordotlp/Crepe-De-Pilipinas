# Crepe de Pilipinas website

A responsive, single-page pastel café website built with HTML, CSS, and JavaScript.

## Files

- `index.html` — page content and sections
- `style.css` — colors, layout, and responsive styles
- `script.js` — mobile navigation and current copyright year
- `images/` — contains your logo and will hold product photos

## Run locally

1. Download and unzip this project.
2. Open the `crepe-de-pilipinas` folder in Visual Studio Code.
3. Open `index.html` in your browser to preview it.
4. Optional: install the VS Code extension **Live Server**, then right-click `index.html` and choose **Open with Live Server**. This refreshes the preview as you save changes.

## Before publishing

1. The Instagram button is already linked to https://www.instagram.com/crepedepilipinas/.
2. Update the product descriptions and prices when they are confirmed.
3. Replace the CSS illustrations with your real product photos when you are ready.
4. Check all details and get permission before publishing any school logos or photos of people.

## Publish using GitHub Pages

1. Sign in to GitHub and create a new repository, for example `crepe-de-pilipinas`.
2. For the simplest setup, make the repository **Public**.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `images` folder contents to the repository's root (not inside another nested project folder).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. GitHub Pages will show your published website URL in the Pages section. It will usually look like `https://YOUR-USERNAME.github.io/crepe-de-pilipinas/`.
8. Whenever you update and commit the files to the `main` branch, GitHub Pages will publish the update.

## Editing the Instagram link

In `index.html`, find:

`href="https://www.instagram.com/crepedepilipinas/"`

If the profile changes, replace the URL with your group's Instagram profile, for example:

`href="https://www.instagram.com/your-account/"`

Use your real account URL, not the example above.

## Notes

- The supplied logo is saved as `images/logo.png`. Product cards currently use CSS illustrations as temporary visuals.
- Prices are intentionally marked “Price to be announced” because final prices have not been provided yet.
- Instagram messages are a contact link, not an automated checkout or order-management system.
- Google Fonts are loaded online. If the visitor is offline, fallback fonts will be used.
